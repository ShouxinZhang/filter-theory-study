# Codex 中的 Claude 导入对话

## 按请求选择操作

- **核实来源或整理清单**。从 Codex 的导入历史或本机导入登记读取 Claude 源路径和目标 Codex 会话 ID，用 ID 关联项目、标题及归档状态。标题相同、引用同一段开场白的对话也可能是独立分支。整理清单时给每条分配编号，方便用户指明确切范围。
- **停止后续同步**。在桌面端设置的 Import 页面关闭自动更新，再读回开关状态。已有副本的去留单独处理。[OpenAI 导入文档](https://learn.chatgpt.com/docs/import)
- **删除已有副本**。将用户确认的清单编号解析成固定的 Codex ID 集合，核实主机与项目，并计入已归档项。用户已确认这组 ID 时直接执行。保留 Claude 原文件，记录哪些源路径在操作前就已缺失。
- **执行与验收**。优先用当前版本提供的删除操作。使用本地 app-server 时先核对协议是否提供 `thread/delete` 及其参数，逐个记录结果。复查目标 ID 已从活动和归档会话中移除，再回到原项目侧栏查看用户指出的标题。只有后端可查时，明确记录界面尚待核验。

## 删除后侧栏仍显示

按目标 ID 区分同名会话、桌面索引残留和旧窗口缓存。先尝试让侧栏重新加载；比较同一项目在新窗口的显示。若仍有残留，查阅[桌面侧栏索引残留案例](references/examples/sidebar-after-delete.md)，按本机版本验证目录与表结构后再决定是否修复索引。
