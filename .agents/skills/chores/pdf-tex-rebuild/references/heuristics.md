# Heuristics

本文件只描述可选自动清点脚本的启发式，不是正文 OCR 规则。最终内容、阅读顺序和对象边界均以页面视觉检查为准。

## 公式锚点识别

优先识别满足以下条件的行：

- 行尾存在形如 `(7)` 的编号。
- 行文本包含明显数学符号，如 `=`, `<`, `>`, `+`, `-`, `sup`, `inf`, `Tr`, `E[`。
- 该行不是 `Figure/Table/Algorithm` caption。

这类对象记为 `equation`，标签形如 `eq:auto-7`。

## 图表锚点识别

优先识别：

- `Figure 3: ...`
- `Fig. 3 ...`
- `Table 2: ...`
- `Algorithm 1: ...`

同一行出现多个 caption 时，分别切片成多个锚点。

## 引用绑定

高置信度模式：

- `Equation 5`
- `Eq. (5)`
- `Figure 2`
- `Table 1`
- `Algorithm 1`

低置信度模式：

- 裸编号 `(8)`

只有当该编号已存在于 `equation` 锚点表时，才将裸编号视为候选公式引用；否则保留为未解析项。

## 失败模式

- 纯图片公式、扫描版 PDF、严重断字会使自动清点失效，此时直接视觉 OCR，不继续堆叠 Python 解析。
- 两栏页面中，同一逻辑段落可能被打散为多行，需人工合并。
- 并排图 caption 可能被提取到同一行，自动切片后仍需复核文本边界。
