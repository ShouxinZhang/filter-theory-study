# Boundaries

## 目标

- 从 PDF 逐页视觉 OCR，生成可继续编辑的正文与中间产物。
- 为公式、图、表、算法建立稳定锚点和可追踪的引用映射。
- 从明确的单栏模板生成 TeX 重建稿，便于后续双语翻译与人工补全。
- 自动裁出 figure 资产，并为后续 `\includegraphics` 回填提供文件。
- 从参考文献列表生成 `.bib` 初稿，降低手工录入成本。

## 非目标

- 不承诺恢复作者原始 LaTeX 宏包、宏定义、BibTeX 组织方式。
- 不承诺自动恢复矢量图、TikZ、原始图片资源或全部表格格式。
- 不承诺所有引用 100% 自动绑定成功。
- 不承诺自动生成出版级质量的 `.bib` 元数据或完美的图裁剪框。

## 产出物职责

- `meta/`：PDF 元数据与工具版本。
- `page-renders/`：直接 OCR 的页面视觉权威。
- `page-ledger.md`：逐页覆盖率与视觉复核状态。
- `raw/`：可选脚本提取的文本层和版面层提示，不是最终正文权威。
- `parsed/anchors.json`：带编号对象的稳定锚点表。
- `parsed/refs.json`：正文引用扫描结果与绑定状态。
- `parsed/report.md`：抽取统计与待人工复核项。
- `rebuild/recovered_stub.tex`：可继续编辑的 LaTeX 骨架。
- 外部目标目录中的 `figures/`：自动裁出的图像资产。
- 外部目标目录中的 `refs.bib`：自动生成的参考文献数据库初稿。

## 人工介入点

- 所有公式默认从页面直接人工重录；文本层只可用于拼写提示。
- 两栏排版、并排图表、跨页 caption 可能需要人工调整。
- 裸编号引用如 `(8)` 会产生低置信度绑定，必须人工复核。
