# Anthropic Editorial 视觉风格参考卡

本目录记录从编排型技术博客数据图中提炼的视觉语言，供 `assets/themes/editorial-academic/` 主题包复用，也可作为新增自定义主题的起点。

## 视觉要点

- 纸面底色与克制边框：浅色卡片使用暖灰纸面 `#FAF9F5`，分割线 `#D1CFC5`，边框 `#E2E0D8`；深色模式通过 CSS 变量自动桥接宿主 `html-tex-doc` 页面色板。
- 高辨识度语义色板：
  - `primary`（矿物绿 `#629987`）：推荐算法或主方法曲线与置信带。
  - `secondary`（陶土橙 `#EB6834`）：基线对照方法（常配虚线与浅色置信带）。
  - `accent`（天青蓝 `#6A9BCC`）：真实轨迹或辅助连线。
  - `aux`（梅紫 `#827DBD`）：第四序列扩展色。
- 开放式 L 型坐标轴：仅保留左下坐标轴与水平主网格线（二维空间轨迹图按需开启淡色垂直虚线网格）。
- 直接标注与白色光晕：关键峰值与终点文字采用 `paint-order: stroke` 配合背景色描边，避免文字被曲线遮挡。
- 排版分工：正文标题与图例采用 New Century（`C059`）搭配标准宋体（`SimSun`）；所有坐标数字与数学变量采用 `Latin Modern Math` 搭配真 Unicode 数学斜体码位。
