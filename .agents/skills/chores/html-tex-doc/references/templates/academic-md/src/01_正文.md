# 绪论与问题形式化 {#sec:intro}

## 基本模型 {#sec:model}

考虑状态向量 $\bm{x}_k \in \R^d$，其递推关系满足

$$ {#eq:demo}
\bm{x}_k = f(\bm{x}_{k-1}) + \bm{w}_k.
$$

由{@eq:demo} 可进一步推导{@thm:demo} 与{@alg:demo}，相关背景参见文献[@demo2024]。

::: 定理 {#thm:demo} 示例有界性

若映射 $f$ 满足全局压缩条件且二阶矩有限，则误差序列依均方有界。

:::

::: 证明

将{@eq:demo} 两端取范数平方并求数学期望即可得证。

:::
