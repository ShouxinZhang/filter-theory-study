链表：结构、操作与复杂度

HTML 正文 + TeX 出图的混合排版示例

引言

数组把元素放在一段连续内存中，因此能以 \(\Theta(1)\) 时间按下标访问；代价是插入与删除需要整体搬移元素。 链表（linked list）放弃连续性：每个元素各自分配一块内存（称为结点）， 结点之间用指针串联。这样，只要拿到某个结点的位置，就能在常数时间内在其后插入或删除， 但按下标访问必须从头逐个走过去。

本文依次介绍单链表的结构（{@sec:singly}）、三个基本操作（{@sec:ops}）、 双向与循环链表（{@sec:variants}），最后在{@sec:compare}给出与数组的复杂度对比。

单链表

单链表的每个结点含两个域：存放元素的数据域 data，以及指向后继结点的指针域 next； 尾结点的 next 为 \(\nil\)。整个表只需记住头指针 head，如{@fig:singly}所示。

设数据域占 \(s_d\) 字节、指针占 \(s_p\) 字节，则长度为 \(n\) 的单链表占用

\[ S(n) = n\,(s_d + s_p), \qquad \rho = \frac{s_p}{s_d + s_p}, \]

其中 \(\rho\) 是指针开销所占比例。元素越小，\(\rho\) 越大：例如在 64 位机器上存放 4 字节整数时， \(\rho = 8/12 \approx 67\%\)，这是链表常被诟病的空间代价。

基本操作

查找

查找值为 \(x\) 的结点只能从 head 起顺序比较。若 \(x\) 等可能地位于 \(n\) 个位置之一， 成功查找的期望比较次数为

\[ \E[C] = \frac{1}{n}\sum_{i=1}^{n} i = \frac{n+1}{2} = \Theta(n). \]

链表结点在内存中分散，顺序访问时缓存命中率也远低于数组，因此{@eq:search}的常数因子在实践中往往更差。

插入

在已知结点 \(p\) 之后插入新元素 \(x\) 只需修改两条指针，过程如{@fig:insert}所示，伪代码见{@alg:insert}。 关键在于顺序：必须先让新结点接上原后继，再让 \(p\) 指向新结点。

{@alg:insert}与表长无关，因此

\[ T_{\text{insert}}(n) = \Theta(1) \quad (\text{已知前驱 } p), \qquad T^{\text{数组}}_{\text{insert}}(n) = \Theta(n). \]

注意{@eq:insert-cost}的前提是“已知 \(p\)”。若只给出下标 \(k\)，仍需先花 \(\Theta(k)\) 时间走到第 \(k\) 个结点。

删除

删除与插入对称：删除 \(p\) 的后继只需让 \(p\) 绕过它（{@alg:delete}）。 但单链表无法在 \(\Theta(1)\) 时间删除结点 \(p\) 本身，因为要修改的是 \(p\) 的前驱的指针， 而找到前驱需要从头扫描。这正是双向链表要解决的问题。

反转

反转是检验指针操作是否熟练的经典问题。{@alg:reverse}用三个指针一次遍历完成。 设原表为 \(\seq{a_1}{a_n}\)，第 \(k\) 轮循环结束时满足不变式

\[ \mathit{prev} \text{ 所指的表} = \seq{a_k}{a_1}, \qquad \mathit{cur} = a_{k+1}\ (\text{当 } k = n \text{ 时 } \mathit{cur} = \nil). \]

{@alg:reverse}返回原表的反转 \(\rev\seq{a_1}{a_n} = \seq{a_n}{a_1}\)，时间为 \(\Theta(n)\)，额外空间为 \(\Theta(1)\)。

证明. 对轮数 \(k\) 归纳验证{@eq:invariant}：\(k=0\) 时 \(\mathit{prev}\) 为空表、\(\mathit{cur}=a_1\)； 若第 \(k\) 轮后成立，第 \(k+1\) 轮把 \(a_{k+1}\) 的指针改指 \(\mathit{prev}\)，使其成为新表头，不变式仍成立。 循环在 \(k=n\) 时终止，此时 \(\mathit{prev}\) 即 \(\seq{a_n}{a_1}\)。每轮常数时间、共 \(n\) 轮，只用三个指针变量。∎

双向链表与循环链表

双向链表的结点再增加一个指向前驱的 prev 指针，于是可以在 \(\Theta(1)\) 时间删除任意已知结点， 代价是每个结点多一个指针，即{@eq:mem}中的 \(s_p\) 变为 \(2 s_p\)。 再把尾结点与头部首尾相连，并引入一个不存数据的哨兵结点，就得到{@fig:doubly}中的循环双链表： 空表与非空表的插入、删除可以用同一段代码处理，无需判断 \(\nil\)。
