# 黑金校徽本地展厅

运行 `bash start.sh`，打开终端给出的地址；默认端口 8841，占用时可运行 `bash start.sh 8842`。
拖动旋转、滚轮缩放、右键平移；按钮支持正面、斜视、背面、自动旋转与复位。
全部资源位于本目录，运行不需要联网；需要 Python 3 和支持 WebGL 的浏览器。
请通过启动脚本访问；直接双击 index.html 会受到浏览器模块加载限制。
