# 交流科学

收纳人机交流的方法与表达示范。当前内容为语气示范，供用户需要时指定阅读。

## 使用方式

1. 用户明确要求阅读本技能或语气示范时，阅读 [语气示范](references/语气示范.md)。
2. 按用户指定的用途选取语体：对话与汇报、技术文档、数学推导。
3. 直接说明结论、职责、动作与结果；依据实际证据填写事实、条件和进度。
4. 用户提出措辞反馈时，先调整当前表达；用户要求更新技能时，再修改对应示范。

示范中的权限、确认和操作条件属于例句背景，实际执行范围以当前任务的授权和约束为准。
