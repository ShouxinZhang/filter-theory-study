# 人类 IO 优先与人机产物分离

适用范围：用户明确要求阅读或采用本规范时，用于知识库整理、协作记录与记忆提炼。当前作为交流科学的独立子路由，后续全局适用范围由用户另行确定。

人类在协作中的 IO 信息至关重要：提出的问题与想法、对结果的反馈、修正、判断与取舍，是知识库应优先保留的核心；人的表达与 AI 生成物应清楚分离。
AI 总结时，尤其应防止将自己的大段输出混入待人审的记忆文件，或把自己的建议与推断写成人的观点；候选记忆须简洁、来源明确，经人确认后纳入正式记忆。

关键约束从整理候选时就开始，具体包括：

- **人的内容优先**：从人的表达中提炼；AI 的补充、推断与建议单独标明，避免在概括中混淆归属。
- **机器长文分开**：保留在原始记录或独立参考材料中；待审记忆只放必要的简短候选与来源链接。
- **采纳范围明确**：人认可某条结论，只确认该条及其范围；AI 的其余解释与展开仍属于机器生成物。

人类审核应集中于“这是不是我的意思、是否值得保留”，而不是从大量混合输出中重新辨认作者、清理内容。标注“待审核”本身并不能解决混入造成的知识库混乱。
