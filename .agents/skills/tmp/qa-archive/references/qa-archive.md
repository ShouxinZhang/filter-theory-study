# 问答归档规范

## 周目录

- 路径: `.agents/.tmp/agent/YYYY-MM-DD_YYYY-MM-DD/`.
- 每周自周日 00:00 起, 至下周日 00:00 前止, 按 Asia/Shanghai 计算; 两个日期分别为该周周日与周六, 例如 `2026-09-13_2026-09-19`.

## 文件命名

- `YYYY-MM-DD_HH-mm_任务名称.md`, 时间取 `TZ=Asia/Shanghai date '+%Y-%m-%d_%H-%M'`.
- 所属周按文件名日期确定.
- 文档开头声明 `agent name: <model slug>`, 无法核实时写 `unknown`.
- 公式排版参考 `.agents/prompts/公式排版.md`; 符号习惯参考仓库内 `习惯.md`.

## README 索引

`archive_tmp.py --file <文档> [--type 类型]` 执行:

1. 解析文档一级标题 `# ...`.
2. 以 `新增<类型>: [标题](周目录/文件名.md)。` 追加到 `.agents/.tmp/agent/README.md` 末尾, 已存在则跳过.
3. 统计各周 `.md` 数量, 刷新 README 顶部周期表.

`--type` 默认 `讨论`, 常用 `推导`, `报告`, `习题`, `记录`.

## 旧文档迁移

- 无日期前缀的旧文档按归档前文件修改日期归档, 并在索引中注明依据.
- 移动既有文档时同步调整相关链接.

## 对话约束

- `.tmp` 内容不在对话中重复.
- 对话回答不超过 8 行, 超出则写入 `.tmp` 文件.
