# Session 专属 memory

## 目录与效力

```text
.agents/.tmp/session/<session-id>/
├── map.md
├── prompts.md
└── memory/
    ├── agent-memory-drafts.md
    ├── memory.md
    └── references/
```

- `agent-memory-drafts.md`：AI 可以主动增删改查，供人类审阅；内容没有规则效力，不得作为已确认用户偏好、任务授权或正式记忆的依据。
- `memory.md`：保存本 session 经人类审核的记忆；人类可直接增删改查。AI 仅按人类明确确认的内容和范围修改，保留现有人类修订。
- `references/`：容纳无法压缩的长说明、证据、图片及其他附件，由条目使用相对路径引用；附件不因被引用而整篇获得规则效力。
- `map.md` 继续记录讨论脉络与待办；`prompts.md` 保留机械导出的记录。两者不自动转为正式记忆。

## 整理与审核

- 没有“总结 memory”请求时，AI 可将有价值的候选写入草稿；保持简洁，不为填充文件而写入。
- 用户要求总结或对齐时，围绕用户选定范围整理候选并提出可审阅文字；“总结 memory”本身不等于认可每条结论。
- 人类明确确认后，只将确认范围写入正式记忆；拒绝、暂缓或尚未回应的条目不能自动转正。人类直接编辑正式文件的结果以当前文件为准。
- AI 修改正式文件前重新读取当前内容；不要整体重生成，不以自身旧副本覆盖人类新修改。
- 每条草稿和正式记忆至多两行 Markdown 物理行：第一行陈述，第二行可选来源或附件链接。署名、标题不计为记忆条目；不要以超长段落规避凝练要求。
- 重内容移入 `references/`，条目只保留结论和链接；人类自己的排版不得被同步器为满足两行规则而擅自改写。
- 不保存密码、令牌或模型私有思维链。来源可引用 `../prompts.md#pN`，避免复制整段对话。
- 将已审核经验写回其他 skill，仍需用户明确要求或确认相应修改范围；正式 memory 不等于修改其他技能的授权。

## 读取范围

继续或恢复本 session 时先读取 `memory/memory.md`；没有已审核条目则不虚构记忆。仅在当前任务需要时打开其引用附件。
草稿仅在整理、修改或人类审阅时读取，不作为正常执行任务的默认依据。不同 session 的 memory 各自独立，不建立仓库共享记忆，也不自动跨 session 汇总；共享层面留待用户实践后决定。

## 初始化与维护

`sync.py subscribe`、单次同步和后台 watch 共用 `memory.py` 初始化器：仅创建缺失的两个 Markdown 模板及 references 目录，署名沿用绑定的源会话。
后台同步脚本只负责初始化和保留文件，不承担内容整理或审核；空文件同样保留，重复同步不改变已有文件的内容与修改时间。
agent 可以主动整理、修改草稿；经人类明确审核后，可以按确认范围修改正式记忆。人类也可直接编辑正式记忆。这些内容操作与后台同步是不同职责。
旧版 session 根目录的 `memory.md` 不自动升级为正式记忆。确认迁移时先保存原件，将未审核内容放入 references 并标明效力；修正移动后的相对链接，必要时保留旧路径的跳转页。
模板位于 [agent-memory-drafts.md](templates/agent-memory-drafts.md) 与 [memory.md](templates/memory.md)。`show/list --json` 返回正式记忆、草稿和附件目录路径，供调用方按需访问。
