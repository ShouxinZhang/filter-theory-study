# 剪贴板图片

在汇报头部启用 `addons: [image-paste]`；本工作区现有汇报与新建骨架已启用。

- 复制截图或图片，在幻灯片画面按 **Ctrl+V**（macOS 为 **Cmd+V**）：图片作为可拖拽块插入当前页，并保存回 Markdown。
- 在右侧 Markdown 编辑框按同一快捷键：在光标处插入图片代码，由原有编辑器自动保存。光标位于页头 YAML 时，插在正文开头，以保留配置。
- 工具栏的“贴图”按钮也可读取剪贴板。若浏览器未授权按钮读取，直接使用 Ctrl+V。
- 普通文字粘贴保持原行为；流程图编辑器、排序面板、备注编辑框和其他输入框各自处理粘贴。
- 双击图片可使用 Slidev 的拖拽和缩放控制。位置写在 `<v-drag pos="…">` 中，也可直接修改 Markdown。

图片按原格式保存到当前汇报 `public/images/pasted-*.{png,jpg,webp,gif}`，Markdown 使用 `/images/…` 相对引用。支持每次 1–5 张图片，总大小不超过 20 MB、每张不超过 5000 万像素。剪贴板需要包含图片数据，仅复制文件路径或图片网址属于文字粘贴。

画面粘贴前，原 Markdown 备份到当前汇报 `.image-paste-history/`。读取和写入之间若文件变化，拒绝覆盖；编辑框模式则沿用侧边编辑器的冲突保护。若上传期间光标所在编辑器已切换或内容改变，会保留草稿并给出已保存图片链接。

上传接口仅供本地开发服务，构建和导出的页面不提供粘贴操作；已保存的图片和排版仍正常显示。新增插件后需要重启开发服务。

测试：工作区运行 `npm run check:images`。浏览器测试应使用独立 talk，并复制其 `public/`，不要链接正式汇报的素材目录。
