# 来源与复用

本目录从 filter-theory-study 的 Slidev 学术汇报工作区整理，保留仓库 MIT LICENSE 与作者署名。共享主题、三个编辑插件、兼容补丁和启动脚本均以源码提供。

作者张守信的汇报示例完整保留于 `talks/filtering`，包括封面个人信息、公式、Draw.io XML/SVG、仿真图片、粘贴图片和致谢背景。HITSZ 校标来源记录位于 `research/hitsz-cover-source/`；图片背景由作者提供。品牌图标和第三方依赖仍保留各自来源和适用权利，仓库许可证不授予学校背书或商标授权。

`research/simulation-data/` 保留生成汇报曲线所需的选取数据及原始来源校验记录。`prepare_simulation_figures.py` 已改为使用随包 CSV 重新绘图；完整实验工程和论文属于原仓库其他目录，不是运行此模板的依赖。历史研究笔记中的临时路径是来源记录，以本目录 README 为现行使用说明。
