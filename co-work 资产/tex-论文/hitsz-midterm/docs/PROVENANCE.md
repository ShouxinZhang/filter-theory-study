# 来源与边界

提取日期：2026-09-15。

## 来源

本资产基于 HITSZ-final-paper-draft 仓库中 midterm-report-rebuild 工作区的 hithesis_midterm_template，并对照 hitsz-midterm-template 技能内的主入口与图表片段。旧技能入口仍含个人信息和过时的算法宏包组合；本资产仅复用其章节与图表组织方式，不照搬旧正文。

学校类文件 hithesisart.cls 与 hithesisart.cfg 原样复制，文件头标识为 hithesis v3.1c，保留作者、版权和 LPPL 声明。本资产不改写这些文件的授权信息。hithesis.bst 保留原作者文件头，并沿用已积累的本地文献样式修改；它不是未修改的上游版本。

## 本地配置

算法模块继承当前报告的 algorithm2e 配置：中文输入输出、五号、行号和 ruled/ lined 样式。参考文献模块继承环境初始化后设置孤行惩罚与条目间距的补丁，不改学校类文件。

入口已模块化；删除与通用骨架无关的宏包。旧主入口的图表五号、节内编号、求和字体兼容设置与浮动体参数保留。短篇末三节连续排版逻辑保留，长章节仍需按实际内容复查分页。

## 迁移排除项

- 原报告封面身份信息、固定报告日期和研究题目。
- 原报告数学论证、研究结论、数值结果和所有实验图片。
- sandbox 报告版本、既有 PDF、构建缓存、审查记录和其他任务目录。

三个 BibTeX 条目仅作为期刊、会议与在线文献的格式测试素材保留，并非原报告内容迁移。期刊示例不保留不必要的访问日期；预印本日期沿用既有核验记录，使用者新增或改换来源时应据实际情况更新。

## 使用范围

当前入口仅面向深圳硕士中期报告；不承诺直接适用于其他校区、学位或毕业论文。学校格式变更应另行核对，不以本地模板代替最新提交要求。
