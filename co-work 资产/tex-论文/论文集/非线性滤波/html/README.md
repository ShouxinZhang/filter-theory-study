# 论文 HTML 副本（Web 双栏实时编辑与双向高亮预览）

本目录是上级 TeX 论文的独立受控 Markdown 副本，由仓库通用技能 `.agents/skills/chores/html-tex-doc` 驱动构建与双栏编辑。
它与 `../main.tex` 互不同步；`import_tex.py` 仅用于最初的一次性导入（重跑会覆盖 `src/`）。

## 启动与构建

```bash
python3 thesis_html.py serve    # 打开 http://127.0.0.1:18767 ，支持 Web 内原地双栏修改或 VS Code 修改即时热补丁
python3 thesis_html.py build    # 仅静态构建一次，产物位于 outputs/site/index.html
```

## 目录折叠、Web 双栏编辑器与双向对齐快捷键

| 功能 | 操作方式 | 说明 |
| --- | --- | --- |
| 内联目录折叠 | 点击正文顶部目录栏 / `收起子节` / 章标题左侧 `▾` | 支持整卡收起或仅看顶层章，状态自动记忆 |
| 浮动目录抽屉 | 右上角 `☰ 目录` 或 `Alt+T` | 任意阅读位置呼出章节目录，支持关键字过滤与当前小节高亮 |
| 开合双栏工作台 | 右上角 `◫ 双栏` 或 `Ctrl+\`（macOS `Cmd+\`） | 左侧多文件行号编辑器，右侧实时排版，中缝可拖拽调宽 |
| 反向同步（右 → 左） | 按住 `Ctrl`/`Cmd` 悬停瞄准，`Ctrl+Click`（或 `Alt+Click`）点击段落/公式/定理/表格 | 自动打开对应 `.md` 并滚至精确源码行与词组；在算法框上 `Ctrl+Click` 打开 `algs/*.tex`，`Ctrl+Shift+Click` 跳至 `.md` 调用处 |
| 正向同步（左 → 右） | 左侧 `Ctrl+Click`、点击行号栏或按 `Ctrl+Alt+J` / `Alt+Enter` | 右侧平滑滚至对应渲染行或公式并双端脉冲高亮；点 `🔗 联动` 可开启光标实时跟随指示 |
| 搜索与保存 | `Ctrl+F` 页内搜索，`Ctrl+Shift+F` 跨文件全局搜索，`Ctrl+S` 保存 | 默认开启 360ms 防抖自动保存，带 `mtime_ns` 乐观锁防覆盖 |

## 受控 Markdown 约定

| 写法 | 含义 |
| --- | --- |
| `# 章 {#label}`，`## 节 {#label}`，`### 小节 {#label}` | 标题，自动编号；`{#label}` 可省 |
| `$x$`；独占一行的 `$$ {#eq:key}` … `$$` | 行内 / 行间公式；带标签才编号 |
| `{@key}`，`{@key\|n}` | 交叉引用：全称（如 `式 (3)`）/ 仅编号 |
| `[@key1,key2]` | 文献引用，键来自 `src/refs.bib`，按首次出现编号 |
| `::: 定理 {#label} 标题` … `:::` | 定理类（定理/命题/引理/定义…）；`::: 证明` 为证明 |
| `- …` 等列表 | 块前后空一行 |
| 以 `<figure`，`<table` 等开头的块 | 原样 HTML（图，表，算法），其中 `$…$` 与引用仍生效 |
| `<!-- … -->` | 注释，不输出 |
