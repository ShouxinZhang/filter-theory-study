# 绪论

## 课题背景与意义

从含噪序贯观测中递推估计动态系统的隐状态，是导航制导、目标跟踪、地球物理资料同化与视觉感知中的基础问题[@kalman1960new,bar2001estimation,sarkka2013bayesian]。线性正态系统的最优递推估计由 Kalman 滤波给出[@kalman1960new]；对于非线性系统，扩展 Kalman 滤波（EKF）与无迹 Kalman 滤波（UKF）[@julier1997new]依靠局部近似传递一、二阶矩，在强非线性或多峰后验下易产生较大偏差。自举粒子滤波（BPF）[@gordon1993novel]以加权经验测度逼近后验分布，摆脱了线性与正态分布假设，成为非线性状态估计的常用非参数工具。

然而，基于重要性加权与独立重采样的粒子滤波在两类情形下存在固有局限：一是当过程噪声极弱甚至为零时，预测步缺乏随机扩散，多项重采样仅能在既有粒子中复制筛选，导致粒子集迅速退化为少数乃至单个支撑点；二是当状态或观测维数较高时，似然权重方差随维数急剧增大[@bengtsson2008curse,snyder2008obstacles]，有限粒子规模下权重集中于个别样本。针对上述瓶颈，引入最优输运确定性变换[@villani2009optimal,reich2013nonparametric]替代随机重采样，并结合低维流形表示与无权重条件输运映射处理高维观测，对于提升弱噪声与高维场景下的滤波精度和实时性具有明确意义。

## 国内外研究现状及分析

1993 年，Gordon、Salmond 和 Smith 提出自举（Bootstrap）粒子滤波，在不依赖线性化或正态假设的条件下实现了递推 Bayes 状态估计[@gordon1993novel]。1994 年，Kong、Liu 和 Wong 围绕序贯重要性采样讨论了权重退化与有效粒子数问题[@kong1994sequential]；1996 年，Kitagawa 在重采样中引入分层采样[@kitagawa1996monte]。此后，Isard 和 Blake 将粒子滤波用于视觉轮廓实时跟踪[@isard1998condensation]，Liu 和 Chen 系统归纳了序贯 Monte Carlo 与重要性重采样通用框架[@liu1998sequential]。为改善提议分布，Pitt 和 Shephard 提出辅助粒子滤波（APF）对粒子作观测预筛选[@pitt1999filtering]，van der Merwe 等结合无迹变换构造重要性分布提出无迹粒子滤波（UPF）[@van2000unscented]，Doucet 等主编的文集[@doucet2001sequential]进一步总结了利用条件解析结构降维的 Rao-Blackwellized 粒子滤波（RBPF），该分解思想随后亦成功用于同步定位与建图（SLAM）等问题[@montemerlo2002fastslam]。

针对重采样后的粒子贫化，一类工作引入 Markov 链 Monte Carlo（MCMC）移动步骤，如 Gilks 和 Berzuini 的重采样-移动算法[@gilks2001following]与 Doucet 等的区块采样方法[@doucet2006efficient]，但在线计算开销较高[@li2017particle]；另一类工作利用核密度平滑恢复连续采样，如正则化粒子滤波（RPF）[@musso2001improving]与核均值漂移粒子滤波（KPF）[@chang2005kernel]，但核带宽选择对维数敏感，主要适用于低维连续状态空间。粒子滤波的退化机理与改进策略亦可参见相关综述[@li2015particlezh,vanleeuwen2019review]。

最优输运理论提供了避免随机复制的确定性样本变换方法[@villani2009optimal,peyre2019computational,ma2019optimaltransportzh]。2012 年，El Moselhy 和 Marzouk 构造了从先验到后验的确定性最优映射[@el2012bayesian]；2013 年，Reich 提出集合输运粒子滤波（ETPF）[@reich2013nonparametric]，以离散最优耦合的条件重心替代随机重采样，克服了集合 Kalman 滤波[@evensen2003ensemble]在非正态后验下的线性近似偏差（渐近偏差）。结合 Cuturi 的熵正则化 Sinkhorn 算法[@cuturi2013sinkhorn]，Corenflos 等提出基于熵正则输运的可微粒子滤波（DPF）[@corenflos2021differentiable]，缓解了重采样不可微问题。Al-Jarrah 等进一步将后验更新归结为条件最优输运问题，利用神经网络通过极大极小对抗优化学习无需似然权重的条件映射（OTPF）及其摊销形式[@aljarrah2023otpf,aljarrah2024brenier,aljarrah2025aotf]。

在神经网络状态空间建模与潜空间滤波方面，Krishnan 等提出深度 Kalman 滤波（DKF）与结构化推断网络[@krishnan2015deep,krishnan2017structured]，Gu 等利用循环网络自适应学习提议分布[@gu2015neural]，Karl 等的深度变分 Bayes 滤波（DVBF）[@karl2016deep]与 Hafner 等的潜动力学模型[@hafner2019learning]从高维像素观测中提取紧凑的无记忆潜状态。Revach 等提出以网络学习增益的 KalmanNet[@revach2022kalmannet]，而 Greenberg 等指出经超参数调优的经典 Kalman 滤波（OKF）在多组基准上仍具竞争力[@greenberg2023optimization]。近期工作进一步探索了基于大语言模型上下文泛化的 LLM-Filter[@liu2025onefilterall]、结合潜空间动力学与集合评分滤波的 LD-EnSF[@xiao2026ldensf]以及高维表示空间中的局部预测学习[@stockl2024localprediction]。

综合现有研究可以看出，离散集合输运（ETPF）虽然消除了多项重采样的随机复制噪声，但它仍依赖似然权重，且新粒子受限于预测粒子的凸包，难以直接推广到高维观测场合。另一方面，神经网络条件输运映射避开了权重计算，但逐步在线对抗训练耗时较长，多步映射的复合也容易累积误差。此外，面对高维观测，这类方法还需要与低维表示学习有效衔接。因此，有必要从统一的视角出发，深入分析离散耦合的误差机理，并进一步探索高维观测下的流形压缩与低开销条件输运滤波。

## 本文的主要研究内容

围绕传统粒子滤波在弱过程噪声下的样本塌缩与高维观测下的权重失效问题，本文结合最优输运理论与神经网络流形学习，从离散耦合变换与连续条件映射两个层次研究无复制的后验粒子更新方法。在低维状态空间中，通过求解预测经验分布与加权后验分布之间的最优耦合（及其熵正则近似），以确定性重心变换直接将预测粒子更新为近似后验粒子；在高维观测空间中，利用压缩与还原流形拟合提取低维潜空间表示，并结合无需计算似然权重的条件输运映射对抗学习与静态后验一步累积性质，形成离线统一训练、在线单次前向推理的潜空间摊销条件输运粒子滤波算法，进而在多组低维与高维数值实验中检验了上述方法的有效性。全文各章的具体内容安排如下：

1. 第1章为绪论，阐述非线性状态估计的课题背景与研究意义，梳理粒子滤波退化改进策略、最优输运滤波方法以及神经网络潜空间滤波的国内外研究现状，并在此基础上分析现有方法的局限性，引出本文的研究脉络。
2. 第2章介绍本文所需的理论基础（相关严格证明归入文末附录），包括统一的测度推前与核复合记号、递推 Bayes 滤波框架、粒子经验测度近似与重采样表示，进而阐述离散 Kantorovich 耦合与熵正则 Sinkhorn 重采样、经验模内积下的压缩与还原流形拟合理论，以及条件输运映射的极大极小对偶表述、局部序贯观测最优识别准则与静止潜状态下后验分布的一步累积表示性质。
3. 第3章展开具体算法设计与机理分析，给出自举粒子滤波与集合输运粒子滤波的递推流程，建立完备内积空间上均方误差的四项正交分解，并从理论上证明零过程噪声与确定性演化下传统重采样走向单点塌缩的指数退化规律；随后给出潜空间摊销条件输运粒子滤波算法，并从新粒子取值范围、跨步误差传播、还原偏差与在线计算复杂度四个方面对比四类潜空间更新机制。
4. 第4章开展数值仿真与对比实验，依次在一维强过程噪声非线性基准、一维零过程噪声混沌 Logistic 模型以及高维含噪 MNIST 手写数字逐窗口序贯识别任务上，将离散集合输运及潜空间摊销条件输运滤波与扩展 Kalman 滤波、集合 Kalman 滤波、自举粒子滤波及逐步在线对抗输运基线进行定量比较，从估计精度、样本多样性与在线推理耗时等方面验证本文理论分析与所提算法的性能表现；最后在结论部分总结全文工作，并讨论研究局限与后续方向。
