# 结论 {#sec:conclusion}

本文提出了一种将线性最小均方递推滤波框架推广至非线性系统的新方法——无迹滤波 [@r08]。通过以确定性构造的 $2n + 1$ 组对称加权采样点直接经由真实非线性映射传播统计矩，无迹滤波在保持与一阶线性化滤波相同渐近计算复杂度 $O(n^3)$ 的同时，取得了三项关键突破：

- **更高的统计矩逼近精度**：对任意非线性变换与对称先验分布均能精确匹配至三阶矩，且在正态假设下取 $n + \kappa = 3$ 还可进一步匹配四阶矩，有效消除一阶线性化的曲率偏差与协方差过度压缩。
- **彻底免除解析求导**：无需推导或编码一阶或二阶偏导数矩阵，可直接作用于复杂连续动力学数值积分器、非加性噪声模型乃至不可微黑盒模块。
- **显著提升强非线性稳定性**：在极坐标坐标变换与五维高超声速再入飞行器雷达追踪两个典型强非线性算例中，无迹滤波在均值、协方差逼近以及未知气动参数瞬态辨识上均展现出优于一阶线性化滤波的精度与稳健性。
