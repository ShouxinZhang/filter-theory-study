# 译校、数值复现与符号对照附录 {#sec:audit}

本中文校订版以 N. J. Gordon、D. J. Salmond 与 A. F. M. Smith（1993）原刊论文为底本，对照仓库符号与术语规范完成了以下校订与复现审核：

- 结构化术语去人名规范：严格按照本仓库《符号习惯》，将数学与物理概念一律改以其数学结构或物理含义命名（如条件概率递推估计、正态分布、线性最小方差递推滤波器、一阶线性化正态滤波器、无后效转移模型、单位点质量广义函数、平面直角坐标与随机抽样仿真等）。首次出现时在圆括号内附注英文原名以利文献检索，后续正文、标题与图题注均只使用结构化中文译名；学者姓名仅在引述具体文献主语及文末参考文献原题中保留。
- 全套数据图确定性数值重算与矢量重绘：{@sec:sim} 中的 11 幅数据图（{@fig:1} 至{@fig:11}）均基于固定随机种子独立重算并生成深浅色自适应矢量图，涵盖一维强非线性算例（$N = 500$，50 步；条件自举滤波器均方根误差为 $3.6598$、95% 区间覆盖率 $90\%$，显著优于一阶线性化正态滤波器的 $20.6309$ 与 $30\%$）以及四维纯方位目标追踪算例（$N = 4000$，24 步；条件自举滤波器终拍位置误差为 $0.00334$、位置与速度 95% 区间覆盖率均达 $100\%$，而一阶线性化正态滤波器发散至终拍误差 $0.94009$）。
- 纯方位观测象限延拓与先验筛选机理补注：针对{@eq:12} 原始反正切记法，在数值复现中采用四象限反正切函数 $\operatorname{atan2}(y_k, x_k)$ 并在 $(-\pi, \pi]$ 区间内执行角度新息缠绕，避免目标穿越坐标轴时发生 $2\pi$ 跳变；同时在{@sec:sim-bearings} 中补充记录了飞越观测器阶段单步超前先验筛选的逐拍拒绝量统计特征。
- 记号与排版统一：多维列向量与矩阵统一采用粗斜体（如 $\bm{x}_k, \bm{y}_k, \bm{w}_k, \bm{v}_k, \bm{\Phi}, \bm{\Gamma}, \bm{Q}, \bm{M}_1, \bm{I}_2$），一维标量算例与标量方位观测保持斜体（$x_k, y_k, z_k, w_k, v_k$）；矩阵转置统一记作 ${}^{\mathrm{T}}$；数学期望与事件概率分别记作 $\mathbb{E}[\cdot]$ 与 $\mathbb{P}(\cdot)$。
