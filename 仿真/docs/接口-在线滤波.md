# 在线滤波公共输入输出

沿用 [符号约定](../../习惯.md) 与 [OTPF](../../粒子滤波/otpf-basic.md); $N$ 为粒子数, $x_k^{\pm,(i)}\in\mathbb R^{n_x\times1}$, $-,+$ 表示预测与后验。
初始化输入: 公开模型 $f_k,h$, 噪声分布, 滤波先验 $p^{\mathrm{init}}$, $N$, 算法配置与独立算法随机流。
模型提供 `sample_initial`, `propagate(k,x,noise)` 与 `log_likelihood(k,y,x)`; 时间下标 $f_k$ 显式容纳非平稳环境。
逐步输入: 当前 $(k,y_k)$ 与内部保存的上一轮等权粒子; 不接收真值, 实际环境噪声或未来观测。
初始化时一维环境先抽取 $x_0^{+,(i)}$ 再传播; 追踪环境直接抽取 $x_1^{-,(i)}$ 并进入加权步骤。
普通时间步的预测与加权定义为
$$
\begin{aligned}
&x_k^{-,(i)}=f_k(x_{k-1}^{+,(i)},n_{x,k}^{(i)}),\;n_{x,k}^{(i)}\sim\mathbb P_{N_{x,k}},\\
&w_k^{+,(i)}=\frac{p(y_k\mid x_k^{-,(i)})}{\sum_{j=1}^N p(y_k\mid x_k^{-,(j)})},\;\bm w_k^+\in\Delta^{N-1},\\
&\hat{\mathbb P}_{N;X_k}^+=\sum_{i=1}^Nw_k^{+,(i)}\delta_{x_k^{-,(i)}},\;\hat x_k=\sum_{i=1}^Nw_k^{+,(i)}x_k^{-,(i)}.
\end{aligned}
$$
这里 $\sim$ 表示抽取实现值, 各粒子的传播噪声独立; 权重在 log 域用 log-sum-exp 归一化。
允许单个 log 似然为 $-\infty$ 表示零权重; 若全部为 $-\infty$ 或出现 NaN, $+\infty$, 返回失败状态与时间索引, 不静默改为均匀权重。
每步输出 `FilterStep`: 环境版本, 轨迹编号, 算法编号, $k$, $\hat x_k$, $(x_k^{-,(i)},w_k^{+,(i)})_{i=1}^N$, $x_k^{+,(1..N)}$, 状态码。
其中加权粒子是当前滤波后验近似, 等权粒子由 BPF 或 ETPF 产生并用于下次传播; 两类表示分别存储。
两算法的主评测点估计都使用等权化前的 $\hat x_k$, 避免把 BPF 当步重采样的额外随机误差混入比较。
完成本步等权化后立即返回当前输出, 输出仅依赖 $y_{1:k}$; 全部后验记录保存在驱动层, 算法递推状态只需当前集合。
内部粒子矩阵使用 $X_k^\pm=[x_k^{\pm,(1)},\dots,x_k^{\pm,(N)}]\in\mathbb R^{n_x\times N}$, 与单个随机状态 $X_k$ 依上下文区分。
驱动层另附单步耗时与算法配置, 内存中的记录完成后统一序列化; 后验均值与所有粒子数值使用 C++ `double`。
误差计算属于评估器; 有效样本数等诊断由输出权重计算, 不改变算法的在线行为。
