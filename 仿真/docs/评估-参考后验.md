# 参考后验计算与有效性

`reference` 为独立 C++ 离线模块, 输入公开模型, 同一滤波初始先验与冻结观测, 输出每条轨迹每个时刻的 $x_k^{\mathrm{ref}},\Sigma_k^{\mathrm{ref}}$ 及精度记录。
参考目标是[额外误差规范](评估-后验额外误差.md)中的 $x_k^\star,\Sigma_k^\star$, 使用与待测算法完全相同的模型, 似然与初始化时序。
每个时刻只使用 $y_{1:k}$, 不使用未来观测, 真值或实际过程噪声; 离线计算不允许把平滑后验冒充在线滤波后验。
一维采用确定性网格积分递推 Bayes 预测和更新, 数值积分输出后验均值与协方差, 不作高斯闭合近似。
逐次减半网格步长与扩大积分区间, 分别检查离散误差和截断误差, 保留双峰结构; 参考配置与收敛容差写入版本清单。
四维采用独立实现的高精度 SMC 参考, 如使用观测引导提议则必须包含正确重要性权重; 转移采样兼容退化状态增量。
逐级增加参考粒子数并使用独立随机种子重复, 分别检查均值, 协方差, 模态占比及 ESS; 单次大粒子数 BPF 不能直接称为精确后验。
至少比较连续三个精度等级, 同时用独立实现或不同提议机制交叉检查; 未验证的参考记录不得用于算法排序。
一维报告网格与区间细化差异; 四维报告独立重复的标准误与粒子数递增偏移, 不能把重复间一致视为无偏证明。
参考均值误差会污染额外误差, 对同一分量集合 $J$ 有
$$
\begin{aligned}
&\hat x_k-x_k^{\mathrm{ref}}=(\hat x_k-x_k^\star)-(x_k^{\mathrm{ref}}-x_k^\star),\\
&\left|\sqrt{D_J^{\mathrm{ref}}}-\sqrt{D_J}\right|\le\sqrt{\frac1{MK}\sum_{m=1}^M\sum_{k=1}^K\sum_{j\in J}(x_{k,j}^{\mathrm{ref},[m]}-x_{k,j}^{\star,[m]})^2}.
\end{aligned}
$$
$D_J^{\mathrm{ref}}$ 表示用参考均值替代精确均值得到的指标; 上式是理论误差界, 右侧未知, 实际须随参考收敛诊断报告可信精度范围。
结果字段使用 `ref` 后缀, 同时报参考方差精度; 算法间差异未超过参考不确定性时标注无法分辨, 不强行宣称优劣。
参考文件随数据版本和 SHA-256 冻结, 两算法共用, 不进入算法输入; 参考计算耗时另列, 不计入在线滤波时间。
固定真实初值版保留 Gordon 原设置; 此时 $D_J^{\mathrm{ref}}$ 衡量对指定模型后验均值的逼近, $B_J^{\mathrm{ref}}$ 不保证等于该数据生成过程的最小实际 MSE。
另定义 `matched-prior` 数据版本: 一维每条真实初值独立抽自 $\mathcal N(0,2)$, 追踪独立抽自 $\mathcal N(\bar x_1,M_1)$, 其余模型和时序保持一致。
在匹配版中滤波器只知道初始分布, 不知道真实初值; 初始粒子与真实初值独立采样, 两算法仍共享同一组初始粒子。
只有匹配版按真实状态, 观测和独立算法随机性取总体期望时, 真值 MSE 才等于平均最小后验 MSE 加平均额外 MSE; 有限轨迹估计仍有采样误差。
两种数据版本分别汇总, 不混合排名; [C++ 实现](../code/README.md)已支持一维网格参考, 四维 SMC 参考仍是待实现规范。
