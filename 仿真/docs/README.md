# C++ 滤波仿真规范

本目录先固定数学规范, 后续以 C++ 实现数据生成, 在线滤波与评估, 三者独立编译与调用。
代码和编译运行说明见 [C++ 实现](../code/README.md)。
- [Gordon 一维环境](环境-Gordon一维.md): 非线性状态与平方观测。
- [Gordon 目标追踪环境](环境-Gordon目标追踪.md): 四维运动与纯方位观测。
- [滤波公共接口](接口-在线滤波.md): 输入, 初始化, 预测, 加权后验与在线输出。
- [噪声接口](接口-噪声.md): 正态/均匀分布, 维度与逐维参数, 环境和算法共同使用。
- [BPF](算法-BPF.md): 转移先验提议与多项式重采样。
- [ETPF](算法-ETPF.md): 无熵正则的最优输运与重心变换。
- [评估](评估.md): 逐时刻误差, 汇总指标与计时边界。
- [后验额外误差](评估-后验额外误差.md): 最优后验均值, 不可消除误差与相对额外误差。
- [参考后验](评估-参考后验.md): 离线参考计算, 精度验证与先验匹配协议。

符号以 [习惯](../../习惯.md) 为准, 粒子按列排列, 输运矩阵方向沿用 [OTPF](../../粒子滤波/otpf-basic.md)。
原论文的过程噪声 $w_k$ 和观测噪声 $v_k$ 分别改记 $N_{x,k}$ 和 $N_{y,k}$; 真实实现值记 $x_k$。
数据模块输入环境版本, 参数, 独立数据种子; 输出固定真值, 观测及清单, 不依赖算法或粒子数。
算法仅接收公开模型, 滤波先验与逐步观测; 真值, 实际噪声和数据生成种子仅供数据模块与评估器使用。
评估模块只读真值, 冻结参考后验与算法输出, 不调用待测算法内部实现, 不将误差反馈给测试中的滤波器。
初版每个环境固定 $M=100$ 条独立噪声轨迹; 此为本项目评测设置, 不表示重现原论文的随机轨迹。
数据清单保存环境版本, 时间索引, 参数, 数据种子, 随机数引擎及正态变换版本, 文件 SHA-256。
冻结后的数据文件是基准依据; 修改参数或数据须创建新版本, 不能覆盖原基准。
算法随机流分为初始化, 传播与重采样, 均与数据生成流独立; 相同重复编号共享初始粒子及按 $(k,i)$ 对齐的传播噪声。
初版每条轨迹运行一次每种算法, 共 $M$ 个配对结果; 算法种子表固定, 多次重复须另列协议版本。
两算法默认每步等权化, 不加 roughening, prior editing, 膨胀或自适应重采样; 扩展方案另设算法标识。
默认粒子数一维 $N=500$, 追踪 $N=4000$; 比较时固定相同 $N$, 扩展扫描须单独记录。
C++ 模块为 `benchmark`, `reference`, `filters`, `evaluation` 与驱动 `runner`; 参考后验离线冻结, 数据与输出预分配在内存, 文件批量读写。
计时区间排除数据生成, 文件 I/O 与评估, 但包含滤波全部计算; 使用 C++ 本身不能消除 I/O 对计时的影响。
