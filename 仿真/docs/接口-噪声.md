# 可配置噪声接口

过程噪声与观测噪声分别记 $N_{x,k}$ 与 $N_{y,k}$, 其维数由模型的噪声入口决定, 不必等于状态维数。
本版支持逐维独立正态分布与矩形区域上的均匀分布, 同一种分布的参数可以逐维设置。
$$
\begin{aligned}
&N_j\sim\mathcal N(\mu_j,\sigma_j^2),\;\sigma_j>0,\\
&N_j\sim\mathrm U[a_j,b_j],\;a_j<b_j,\;j=1,\dots,d,\\
&\log p_N(n)=\sum_{j=1}^d\log p_{N_j}(n_j).
\end{aligned}
$$
接口输入分布类别, 正整数 `dim`, 均值/标准差或下界/上界; 单个参数广播到全部维度, 参数数组必须恰有 `dim` 项。
正态接口采用标准差 `stddev`, 文中正态分布记号的第二参数仍为方差; 当前不提供相关高斯协方差接口。
接口提供 `sample(out,rng)`, `sample_component(j,rng)`, `log_density(value)` 及可序列化的分布描述。
均匀分布支持集外的对数密度为 $-\infty$; 若全部粒子的观测似然为零, 滤波明确失败, 不修改噪声或重置权重。
环境的 `transition(k,x,noise,out)` 与 `measurement(x)` 负责确定性映射, 环境包装层负责噪声采样和加性观测似然。
一维环境的过程/观测噪声维数均为 1; 追踪过程噪声维数为 2, 观测噪声维数为 1, 不匹配时拒绝接入。
噪声参数冻结在观测数据的公开模型描述中; BPF, ETPF 与参考求解器从同一描述恢复噪声模型。
物理噪声随机流与粒子传播随机流相互独立; 本次拆分复用分布配置, 真实噪声样本库另行扩展。
