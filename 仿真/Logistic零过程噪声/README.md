# Logistic 平方观测: 仅改变 Q 的对照

以此前的 Q=10⁻⁴ 实验（未收入本仓库）为基准, 只把物理模型和粒子预测中的过程方差改为 $Q=0$。
其余保持 $R=0.1$, $N=128$, $X_0\sim U[0,1]$, $h(x)=x^2$, seed=`202609142122`, 64 条路径×1000 步×32 次独立算法重复。
初始化及所有随机流保持; 真值随 Q 改变而重新生成, 观测噪声保持配对。每步仍消费一个高斯过程随机数再乘零, 状态传播没有人工噪声。
镜像反射规则保留, 但确定性 Logistic 将 $[0,1]$ 映入自身, 本次反射不改变位置。真值第 2–1000 步相对确定性方程的最大残差为零。
BPF 仍调用 `仿真/code` 的多项式重采样, ETPF 仍调用一维无正则最优输运, 均每步执行。没有改用旧报告的系统重采样。
Q=0 的后验参考直接复用 [theta 网格有限体积程序](reference.cpp), 避免沿用非零 Q 的转移核。8192/16384 格加密, 采用后者, 后验均值最大变化 1.65e−6。
四项定义与上一报告相同。偏差平方使用 $(\bar x-m)^2-s^2/32$, 算法波动使用重复输出的无偏样本方差。总 MSE 是每次输出的平方误差再平均。
Bayes 项来自条件后验方差, 因此实测四项与总 MSE 的差还包含真值残差的抽样波动和经验交叉项; 完整展开的最大残差为 1.76e−19。
新增塌缩记录只做诊断, 不改变滤波行为。BPF 2048/2048 次运行最终为单点, 首次单点时刻中位数为 16; ETPF 0/2048 次到达单点。
