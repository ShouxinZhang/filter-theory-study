# 正态与均匀噪声

接口在 [noise.hpp](../include/pf/noise.hpp), 数学约定见[噪声规范](../../docs/接口-噪声.md)。
`Noise` 支持逐维独立分量, `dim` 为正整数; 正态配置是均值和标准差, 均匀配置是下界和上界。
```cpp
auto gaussian = pf::Noise::normal(3, 0.0, 2.0); // 三维, 每维均值 0, 标准差 2
auto uniform = pf::Noise::uniform(3, -1.0, 1.0);
pf::Vector mean(2), stddev(2); mean << 0, 0.1; stddev << 0.001, 0.002;
auto per_dimension = pf::Noise::normal(mean, stddev); // 也支持逐维 lower/upper
pf::Random rng(42); pf::Vector value(3); gaussian.sample(value, rng);
double log_p = gaussian.log_density(value);
auto restored = pf::Noise::decode(gaussian.encode()); // 分布参数可序列化复用
pf::EnvironmentNoise config; config.process = per_dimension;
config.observation = pf::Noise::uniform(1, -0.01, 0.01);
auto model = pf::make_environment("tracking", config); // 直接供 ParticleFilter 使用
```
CLI 从 `仿真/code` 执行, 参数单值广播, 逗号列表必须恰好有 `dim` 项:
```bash
build/filter_bench generate --env tracking --out data/custom --trajectories 2 --process-noise normal --process-dim 2 --process-mean 0,0.0001 --process-std 0.001,0.002 --observation-noise uniform --observation-lower -0.01 --observation-upper 0.01
build/filter_bench run --data data/custom --out runs/custom-bpf --algorithm bpf
build/filter_bench run --data data/custom --out runs/custom-etpf --algorithm etpf
```
未指定的入口保持原基准正态参数; 切换成均匀分布时默认区间为 `[-1,1]`, 应按环境需要设置。
噪声接口本身可用任意合法维数; 现有一维环境要求过程/观测维数 1/1, 追踪要求 2/1, 不匹配会报错。
`generate` 将有效噪声描述追加到公开模型的 `noise-v1` 字段, 该字段替代基础模型中的默认噪声; `run` 自动恢复, 无须重复配置。
真实数据与粒子传播仍使用独立随机流; 当前保存复用的是分布配置及已生成数据, 尚未增加独立的真实噪声样本库。
一维参考积分同步使用新噪声, 均匀密度不连续时可能需要更细网格; 精度未通过仍标为未验证。
均匀似然可能使全部粒子权重为零, 此时记录失败; 不自动拓宽区间或更改算法。
