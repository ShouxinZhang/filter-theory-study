# 输出与评估约定

数据目录的 `observations.bin` 仅含公开环境参数和观测; `truth.bin` 单独保存真实初值与各步状态。
自定义噪声分布及全部逐维参数属于公开环境描述, 包含在观测文件 SHA-256 中; 算法与参考均从该描述恢复。
`manifest.txt` 记录版本, 参数, 数据种子, 正态生成方法和 SHA-256; `run` 命令不读取私有清单或真值。
随机数引擎与 Box-Muller 变换固定; 不承诺不同 `libm` 的超越函数逐位相同, 跨机器复现以冻结数据文件为准。
每条结果为 `trajectory-ID.bin` 加 `.sha256`, 格式固定小端, 保存完整粒子, 权重, 在线均值, 耗时与输运诊断。
运行信息文件记录编译器, 构建类型, CPU, 线程数, 求解器与算法参数; Release 默认采用 CMake 的优化选项。
评估输出:
- `steps.csv`: 每步有符号误差, 平方误差, 分量 MAE, ESS, 等权化均值偏移与耗时。
- `metrics.csv`: 各轨迹及总体 RMSE/MAE, 最优参考 MSE, 额外 MSE, 额外 RMSE, 相对误差及参考精度。
- `by_time.csv`: 各时刻完整成功轨迹的 RMSE 与轨迹数量。
- `timing.csv`: 初始化耗时, 在线总耗时, 单步中位数和 95% 分位数, 单位为毫秒。
- `status.csv`: 每条轨迹的成功状态与失败原因; `说明.txt` 给出总数与失败数。
`position` 为分量 0/2, `velocity` 为 1/3; 分量编号在 C++ 和 CSV 中从 0 开始。
主均值使用等权化前的加权粒子; ESS 也使用等权化前权重, 不用恒为 N 的等权集合计算。
主相对指标 `rho_ref` 是平均额外 MSE 除以平均最优参考 MSE, 不平均逐步比值, 不相减两条 RMSE 曲线。
`posterior_mse_ratio_ref` 为 $1+\rho$, `posterior_rmse_ratio_ref` 为 $\sqrt{1+\rho}$; 仅指模型后验风险。
参考缺失, 未验证或分母精度不足时输出 `NA`; 参考误差估计来自细化差异, 不是严格误差上界。
算法差异与参考均值精度相当时不能据此排名, 后验均值精度也不代表完整分布精度。
失败轨迹使全集 RMSE 不可用, 成功子集单列; 跨算法比较须使用相同的完整成功轨迹集合。
单步计时包括传播, 加权, 重采样或输运, 输出构造与内存复制; 排除预热, 数据生成, 文件写出和评估。
API 数值验证失败抛出异常, 驱动转换为失败轨迹; 不静默改为均匀权重或改用熵正则解。
