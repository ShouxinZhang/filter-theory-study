# 运行与续跑

以下命令均从 `仿真/code` 执行, `build/filter_bench help` 显示完整参数。
噪声类别, `dim` 与逐维参数的用法见[噪声配置](噪声.md); 噪声参数在 `generate` 时冻结。
目标追踪与先验匹配数据:
```bash
build/filter_bench generate --env tracking --variant matched-prior --out data/tracking
build/filter_bench run --data data/tracking --out runs/tracking-etpf --algorithm etpf --particles 100
build/filter_bench run --data data/tracking --out runs/tracking-etpf --algorithm etpf --particles 100 --resume
```
`--variant fixed` 保留 Gordon 固定真实初值; `matched-prior` 每条轨迹从滤波初始先验独立抽真实初值。
数据默认种子为 `1993`, 算法默认种子为 `20260914`; 相同算法种子表使两算法共享初始粒子和传播噪声。
每条完整或失败轨迹保存一个检查点; `--resume` 核对数据摘要, 粒子数, 算法, 种子及输运配置, 跳过已记录轨迹。
当前轨迹中途退出时只重算该轨迹; 完成文件使用临时文件加摘要提交, 损坏文件拒绝读取。
已有失败轨迹保留为失败, 改配置或重试请使用新的输出目录; 不覆盖已有基准数据或报告。
`--threads N` 并行不同轨迹, 单条滤波与输运核使用一个线程; 时间比较建议固定 `--threads 1`。
一维后验参考与额外误差:
```bash
build/filter_bench reference --data data/gordon --out runs/reference
build/filter_bench evaluate --data data/gordon --runs runs/etpf --reference runs/reference --out runs/etpf-reference-report
build/filter_bench export --file runs/etpf/trajectory-0.bin --out runs/trajectory-0.csv
```
参考默认比较三档网格, 扩大区间并用梯形积分交叉核查; 未达容差返回退出码 `2`, 评估中额外误差为 `NA`。
内置参考求解器目前只支持一维; 四维可计算真值 RMSE/MAE, 独立四维参考实现可通过 `ReferenceRecord` 接口接入。
`run` 有失败轨迹时返回 `2`, 其他参数或文件错误返回 `1`; 成功返回 `0`。
所有生成数据与构建目录均在 `.gitignore` 中, 源码与数学文档可以直接纳入 Git。
内存检查可用 `cmake -S . -B build-sanitized -DCMAKE_BUILD_TYPE=Debug -DFILTER_SANITIZERS=ON` 重新配置后编译并运行 CTest。
