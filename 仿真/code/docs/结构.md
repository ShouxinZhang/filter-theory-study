# 模块与输入输出

```text
include/pf/                 公共头文件与记录格式
src/core/                  数值工具, 随机流
src/noise/                 正态/均匀分布, 采样/密度与参数序列化
src/environment/           公开模型, 先验, 传播与似然
src/benchmark/             生成冻结观测与私有真值
src/transport/             一维质量匹配, 多维网络单纯形
src/filter/                在线粒子滤波与重采样
src/reference/             离线一维网格参考
src/io/                    二进制序列化, SHA-256 与检查点
src/evaluation/            误差计算与表格输出
apps/                      解析参数, 分派与运行调度
tests/                     数学契约与完整命令流程验证
third_party/pot/           固定提交的 C++ 求解内核与许可证
```
`Environment`: `transition` 接收上一状态与噪声实现值, `measurement` 计算确定性观测; 公共包装层采样并用所配噪声计算似然。
真实固定初值仅位于 `benchmark`, `ParticleFilter` 不接收真值或数据集对象。
`ParticleFilter(model, config, trajectory)` 初始化后, 依次调用 `step(k, y_k)` 得到 `FilterStep`。
`predicted` 对应 $X_k^-$, `weights` 对应 $\bm w_k^+$, `posterior` 对应 $X_k^+$, `mean` 对应 $\hat x_k$。
两个粒子矩阵均为 `n_x × N` 列主序 `double`; 单步输出按值拥有数据, 后续调用不会修改已返回记录。
`RunRecord` 保存环境版本, 数据摘要, 算法配置, 轨迹编号, 完整单步输出和失败位置。
`evaluate_trajectory(truth, run, reference)` 完全独立于滤波库, 返回逐步误差和可汇总平方误差。
各层对应独立 CMake 库目标; 主程序仅调度, 核心库不会在粒子循环中执行文件 I/O。
多维输运依赖 [POT 内核](../third_party/pot/README.md), 保留来源, 固定提交, 许可证与文件校验值。
