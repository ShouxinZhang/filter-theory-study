  - [x] 不默认保存每一步的完整粒子或耦合矩阵，仅对指定轨迹保存诊断快照，防止输出量主导实验成本

实验矩阵建议，$N$ 对 BPF/ETPF 表示粒子数，对 EnKF 表示集合成员数，EKF 不随 $N$ 重复运行，$\varepsilon$ 只作用于 ETPF

| 项目 | 建议设置 |
|---|---|
| 主数据集 | 100 条独立轨迹，每条400步，另设独立的小型开发集 |
| 粒子或集合数 | $N\in\{100,250,500,1000\}$ |
| 观测间隔 | $m\in\{1,2,4,8\}$，横轴同时标相对帧率 $1/m$ |
| 正则强度 | $\varepsilon\in\{0.01,0.1,1,10\}$，作用于未归一化平方代价 |
| 求解控制 | 双边缘总质量误差容限暂定 $10^{-8}$，最大迭代数由开发集预运行确定后冻结 |
